FinTrust Microservices System Architecture
Full-Stack Design
PHP 8+ Microservice (Port 8000)
  • Authentication: JWT token issuance (HS256) & RBAC.
  • Organization Management: Corporate entities & employee rosters.
  • Document Handling: S3 storage abstraction & SHA-256 checksums.
  • Reporting APIs: Summary aggregations & compliance reports.
  • API Gateway / Proxy: Dispatches to Java service with zero-downtime resilient failover.
Java Jakarta Servlet Microservice (Port 8080)
  • Transaction Processing: High-throughput financial ledger intake.
  • Ledger Verification: Double-entry balancing & duplicate detection.
  • Risk Engine: Rule-based risk score calculations (0-100).
  • Audit Trail: Immutable event logging & change capture.
  • Deployment: Jakarta Servlet 6.0 / Apache Tomcat & Standalone runner.
PostgreSQL Database Schema & Tables
users (id, email, password_hash, role)
organizations (id, reg_no, tax_id, risk_tier)
employees (id, org_id, user_id, designation)
transactions (id, ref, amount, risk_level)
ledger_entries (id, tx_id, debit, credit)
risk_scores (id, tx_id, score, rules)
alerts (id, alert_code, severity, status)
audit_logs (id, action, old_val, new_val)
documents (id, s3_key, checksum, size)
